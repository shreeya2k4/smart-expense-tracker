# Smart Personal Expense Tracker

## Abstract
The Smart Personal Expense Tracker is a Python-based web application developed to help users record income and expenses, categorise transactions, monitor monthly budgets and analyse financial habits through interactive charts.

## Objectives
- Maintain digital records of income and expenses.
- Categorise and analyse spending.
- Set monthly budgets and identify overspending.
- Generate downloadable financial reports.
- Store transaction data in an SQLite database.

## Modules
1. Dashboard
2. Transaction Management
3. Budget Planner
4. Reports and Insights
5. Database Management

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Installation
1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

## Expected Outcome
A working web application that helps users track their finances and understand their spending patterns.
